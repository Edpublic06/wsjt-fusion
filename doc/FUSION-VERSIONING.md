# WSJT-Fusion versioning

WSJT-Fusion 1.0.0-beta1 is an independent fork maintained by F6FDY.
Baseline: WSJT-Z 2.0.19 by SQ9FVE, based on WSJT-X 3.0.0.
WSJT-X 3.3.0-beta1 engine and JTTY integration remains in progress.
FT2 provenance and imported revisions are recorded in UPSTREAM-SOURCES.md.

Fusion versions advance independently: patch for fixes, minor for compatible
features or engine updates, major for significant compatibility changes.
Beta releases precede the corresponding stable release.

Historical source names, licenses and attribution are retained.
The WSJT-X application/settings identity, executable names, IPC keys and
standard settings schema remain unchanged for compatibility with existing
profiles and companion applications. Fusion-specific settings keep their
private Edpublic06 namespace. Display names and package names use Fusion.
The historical integration branch name is retained to preserve links.
